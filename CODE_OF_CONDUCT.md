# Code of Conduct

easyskillz contributors must make participation safe, constructive, and focused on the work.

## Expected behavior

- Be respectful and specific when reviewing ideas or code.
- Challenge technical claims with evidence, not personal attacks.
- Respect privacy and never publish another person's credentials, private data, or security report.
- Accept maintainer decisions about scope, safety, and release readiness.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized conduct, sustained disruption, deliberate disclosure of private information, and retaliation are not tolerated in project spaces.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile. Maintainers may edit or remove content, reject contributions, or temporarily or permanently restrict participation. Enforcement decisions should be proportionate, documented privately, and avoid exposing reporters unnecessarily.

This policy applies to project repositories, issue trackers, pull requests, discussions, and project-related public events.
